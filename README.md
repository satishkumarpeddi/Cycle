# Cycle 🚴‍♂️  
### Futuristic AI-Powered Cycling Assistant

# 📌 Overview

Cycle is a futuristic AI-powered cycling assistant Android application designed to provide real-time ride analytics, GPS speed tracking, AI-based calorie estimation, and a premium cyberpunk dashboard experience for cyclists.

The application combines:

- GPS-based speedometer
- AI calorie estimation
- OpenCV + MediaPipe face tracking
- Real-time distance monitoring
- Futuristic neon UI
- Ride analytics dashboard

The goal of this project is to build a modern smart cycling assistant with computer vision and intelligent ride monitoring features.
